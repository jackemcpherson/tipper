# One Production Predictor with Permanent per-Match Locks

Keep one Elo/PAV model and one production rebuild. Source revision identifies
issued behaviour. reviewed branches replace config promotion and shadow models.
The corrected normal probability calculation receives a new model identity.

Every publication retains an authoritative capture linked to the compatibility
projection. Optional primary archives could not establish which tip Tipper issued.
Checked D1 finalisation admits a complete mutable set atomically and rejects
stale runs, changed fixtures and crossed deadlines.

Lock each match at its recorded kickoff. Whole-round locking prevented late
lineups and earlier completed results from improving later matches. A deadline
can move before it passes. it never reopens afterwards. Preserve historical
captures when current fixtures change and leave missed tips missing.

AFL-MCP owns UTC source instants, atomic lineup replacement and shared migrations.
Native prepared D1 SQL remains the documented minimal-Worker exception. HTTP,
scheduled execution and Squiggle are small adapters to prediction, publication
and competition evidence. No additional execution or persistence framework is
necessary for a bounded round transaction.
